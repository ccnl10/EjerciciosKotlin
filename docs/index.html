El ejemplo del zoo

La jerarquía de animales que estudiaste en Java, escrita en Kotlin. Fíjate en lo que cambia: open, los dos puntos para heredar y las interfaces sin paréntesis.

class Perro(nombre: String) : Canino(nombre), Mascota {
    override fun hacerRuido() = println("$nombre: ¡Guau!")
    override fun jugar() = println("$nombre persigue la pelota")
    fun traerPalo() = println("$nombre trae el palo")
}

// Polimorfismo: cada animal, a su manera
for (a in animales) a.hacerRuido()

Ponlo en marcha

Necesitas IntelliJ IDEA y un JDK 17 o superior.

  1. Descarga el proyecto o clónalo.
  2. En IntelliJ: File → Open y elige la carpeta EjerciciosKotlin.
  3. Abre src/Main.kt y pulsa ▶ junto a fun main().
  4. Escribe el número de una opción y pulsa Intro.
